# Security and responsible use
This is an authorized defensive research prototype. It does not execute files;
do not execute suspicious samples on a normal workstation. Use isolated analysis
environments for malware handling. Do not upload malware executables, private
datasets, secrets or identifying sample metadata to issues or pull requests.
Load only trusted models; joblib/pickle files can execute code while loading.
Use the API on loopback; authentication and production hardening are not implemented.
A prediction is not a verified verdict. Document uncertainty and evaluate drift.
Report sensitive vulnerabilities through a private maintainer channel or GitHub
private vulnerability reporting if enabled. No security contact address or
response-time commitment has been verified. Only the current research tree is maintained.
